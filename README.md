# 选题工作台 · 微信公众号创作助手

一个可以放进 GitHub 作品集、也能日常使用的公众号选题程序。填写账号方向、目标读者、写作目标、关键词和手边素材，得到选题切入角度、文章标题、文章开头与分段大纲。第一版专注微信公众号。

## 运行

安装 Node.js 22 或更新版本后，在本项目目录运行：

```sh
npm start
```

打开 <http://127.0.0.1:4180>。项目使用 Node.js 标准库，不需要安装第三方依赖。若端口被占用，可先设置环境变量 `PORT` 为其他端口。服务只监听本机 `127.0.0.1`。

## 两种生成方式

**灵感模板**：不需要账号、API Key 或联网。根据填写的账号定位和素材组织选题，适合先体验写作工作流。结果明确标注为模板，不代表大模型生成，也不预测爆款、阅读量或实时热度。

**AI 生成**：使用你配置的模型服务，结合输入生成不同的公众号选题。它会输出 9 条选题，以及每条的文章标题、切入角度、适合原因、开头、3～6 段大纲、3 个备用标题和待准备素材。服务器校验输出；配置缺失、超时或格式不完整时会明确报错，不会悄悄返回模板冒充 AI。

此版本不抓取实时热点、不自动发布文章。建议把自己的观察、采访、评论或参考材料放进“素材”字段，再核对生成内容中的事实。

## 接入真实 AI

1. 把 `.env.example` 复制为本机的 `.env`。
2. 在 `.env` 填入模型服务的基础地址 `LLM_BASE_URL`、有权限使用的模型名称 `LLM_MODEL`、API Key `LLM_API_KEY`。
3. 重启程序，在工作台切换到 AI 生成。

例如使用支持 Chat Completions 的服务时，基础地址通常以 `/v1` 结尾，程序自动追加 `/chat/completions`。程序默认请求 JSON mode；如果服务不支持，可将 `LLM_JSON_MODE` 改为 `false`。模型仍需按提示返回完整 JSON。

模型名称不设默认值，填写你实际可用的名称即可。兼容接口的具体模型和计费以提供商为准。API Key 只保存在你电脑的 `.env` 或服务器环境变量中，不写进网页、不返回浏览器、不输出到运行日志。不要把密钥发到聊天里或提交到 GitHub。配置 AI 后，点击 AI 生成会把此次输入交给你选择的模型服务。

收藏、排期和账号定位保存在当前浏览器的本地存储中。换设备、换浏览器或清理浏览器数据后不会自动同步，重要内容请导出备份。

## 检查

```sh
node --test tests/*.test.mjs
```

后端测试使用假模型服务，不消耗真实 API 额度，覆盖输入校验、未配置提示、模型输出校验、请求超时、错误信息和静态文件边界。

## 项目结构

```text
public/                 网页界面和离线灵感引擎
server.mjs              本地静态服务器与 API 路由
lib/topic-ai.mjs        AI 提示词、模型请求与结构校验
tests/                  本地引擎和后端测试
.env.example            模型服务配置示例
```

前端只请求同源 `/api/status` 和 `/api/generate`。`GET /api/status` 只返回模型是否可用及模型名称，`POST /api/generate` 接收 `{ "profile": { ... }, "seed": 0 }`。服务不开放 `.env`、根目录源文件或跨站调用生成接口。

发布为纯静态网页时可使用灵感模板、收藏和导出；真实 AI 生成需要运行配套服务。若以后部署为多人服务，需另外加入登录、用户隔离、额度控制和持久化存储。
